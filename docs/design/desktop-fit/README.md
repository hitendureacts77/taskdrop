# Desktop fit

Desktop fit is the work that makes TaskDrop fill a laptop or big-monitor browser instead of showing a stretched phone screen with empty gaps on both sides. It was started on 15 Nov 2026 after the owner saw those gaps on a 1920 × 1080 Chrome at 90% zoom (2133 CSS pixels wide), and it is built on branch `feat/desktop-fit` in five slices. From 1024 wide up, the whole app scales by CSS zoom (1.0 to 1.35, one curve in `apps/mobile/src/lib/layout.ts`); the FEED, READ, FORM and FULL columns are fluid; one top bar (bell, messages, avatar) sits on every desktop screen; the map and the tour work under zoom; Home, Wallet, Help and Notifications fill the width; and Task detail, Profile, Public profile and Settings become two panes from 1440 wide. It is desktop only: the phone, tablet, Android and iOS layouts are untouched. The plan, with the measurements and the fixes D1 to D21, is in [PLAN.md](PLAN.md); `before/` and `after/` hold the pictures.
