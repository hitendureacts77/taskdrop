App changes (small)

  1. Signed out no longer resets to the sign-in screen; Home is the start. The splash stays.
  2. Header: for guests the bell, messages and avatar are replaced by one “Sign in” pill.
  3. Every “needs an account” line and last-step button opens one pop-up first: “Make your account to post” (headline per action), with Create account, Sign in, and Not now. Create account opens AccessScreen’s three steps in a sheet: same fields, same server calls, same consent line.
  4. Setup after sign-up: “About you” now (display name is required to post), the other steps later (decision 3).
  5. Drafts (lib/drafts) also work with no account and move over at sign-up.
  6. My Tasks, Wallet and Profile show their real layout with zeros, plus one “Sign in” line. Nothing locks the screen.

Server changes

  1. Today every api call refuses without a sign-in (“Sign in first”). Guests need read-only calls for the feed, services, map pins and the nearby pulse: area names only, rate-limited, App Check.
  2. The AI writer for guests, with a daily limit per device (each run costs money).
  3. Posting, offers, money, chat and saves stay refused without an account. The server still decides.
  4. No tracking or identifying cookies before sign-up (DPDP: under-18 visitors). Only plain counts.
